# CLAUDE.md

Guidance for Claude Code when working in this repository.

## About this project

The Insect Hotel is a whimsical, boutique-hotel-styled website (built with
[MkDocs](https://www.mkdocs.org/) using the Material theme) that presents an
insect hotel as if it were a luxury retreat for six-legged guests. Content
lives in `docs/`, theme overrides in `overrides/`, and configuration in
`mkdocs.yml`.

## Writing style

- **Write in British English.** Use British spellings and conventions
  throughout (e.g. *colour*, *favour*, *neighbour*, *organise*, *traveller*,
  *centre*, *recognise*). This applies to all site content, template text,
  and documentation.
- **Do not use em dashes (—).** They are not used anywhere on the site. When a
  dash is needed, use a spaced en dash (` – `), which is the British-English
  convention, or rephrase with a comma, colon, or brackets.
